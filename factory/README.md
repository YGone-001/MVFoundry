# Factory Engine Quickstart

The reusable engine is in this directory. Song productions stay outside the repository under `MV_WORKSPACE_ROOT`.

## Build and test

```bash
npm run typecheck
npm run build
npm test
```

`npm test` regenerates the synthetic audio/image fixtures, compiles the engine and runs the tests. Synthetic binaries are ignored by Git.

## External workspace

```bash
export MV_WORKSPACE_ROOT=/absolute/path/outside/this/repository
npm run seed:examples
```

The seed command builds the engine, generates fixtures and creates the four synthetic declarative/module projects plus their directory skeletons.

## Preview and render

```bash
npm run compositions
npx remotion studio factory/src/entry.tsx

npm run render:project -- --project synthetic-pixel-demo --mode video --frames 0-23
npm run render:project -- --project synthetic-module-pixel-demo --mode video --frames 0-47
npm run render:project -- --project synthetic-module-layered-demo --mode still --frame 20
npm run media:seed
npm run media:verify
npm run audio:seed
npm run audio:verify
```

Set `REMOTION_BROWSER_EXECUTABLE` or `CHROME_PATH` when Remotion cannot locate a browser. Video encoding requires system FFmpeg on `PATH`; media/audio seeding, format probing, normalization and muxing also require FFmpeg and FFprobe.

## Video and Hybrid media

`video` shots use approved local H.264 MP4 sources with SHA256 and FFprobe validation, output-frame-aligned source in-points, fit/scale and muted source audio. `hybrid` shots compose a video background, ordered transparent PNG layers and a deterministic Canvas overlay. Media projects are generated by `media:seed` into an external workspace; `media:verify` renders stills and complete videos and checks decoded colors, cuts, layer/overlay evidence, audio policy and source hashes.

## Audio

The master `audio` supports WAV (16-bit PCM), MP3, FLAC and AAC-in-M4A, identified by content and verified by decoded duration. Optional `audioTracks` add approved SFX, voiceover and ambience with frame ranges, source in-points, gain, fades and bounded automation. One deterministic PCM mix (44.1/48 kHz stereo) is built under the external project cache and is the only source for the final AAC stream; nonzero render subranges slice the corresponding sample interval. Analysis is a deterministic RMS/peak/onset foundation with estimated provenance, not tempo/section/lyric understanding. `audio:seed`/`audio:verify` exercise MP3, FLAC, M4A-AAC, multitrack gain/ducking, 44.1 kHz rounding, subrange alignment and decoded-output evidence. See `docs/project-config.md` §5 and `docs/rendering.md`.

## Project scene modules

A project may declare trusted Canvas 2D modules under its own `scenes/` directory. The loader checks the manifest path, SHA256 and source policy; the renderer stages verified copies and a generated entry under `<project>/cache/engine-bundle/`, bundles locally and binds `project:<id>` renderers. Project code is never copied into this repository and module functions are never sent through Remotion input props.

`npm run verify:modules` expects a seeded `MV_WORKSPACE_ROOT` and a usable browser. It bundles both module examples, renders boundary/hold stills and writes `<project>/reports/module-render-evidence.json`. See `docs/project-config.md` §4.1 and `docs/workspace-safety.md`.

## Safety

- `MV_WORKSPACE_ROOT` must be outside this repository and must not contain it.
- Never place production audio, images, scene modules or renders in this repository.
- The renderer stages only approved, hash-verified assets and declared, hash-verified modules into the external project cache.
- Approved video assets are FFprobe-validated; Hybrid layer PNGs must be 8-bit alpha PNGs. Embedded video audio is muted.
- Approved audio sources are probed/decoded locally; normalized copies, mixes and analysis reports stay under the external project cache/reports. Source audio is immutable.
- Hash verification proves byte identity, not that module code is benign. Only run trusted local modules.
- Do not commit or push without explicit authorization.
